# Project Constitution

`constitution/` は、プロジェクトにおける最上位の規約を置くディレクトリです。

## 優先順位

このリポジトリ内では、憲法はすべての `AGENTS.md`、skill、設計書、慣習、実装上の都合より優先します。

- 作業対象に関係する憲法を、実装や設計判断の前に読む。
- 下位の規則で憲法を上書きしない。
- 規則同士が矛盾する場合は憲法に従う。
- 憲法を変更する場合は、ユーザーの明示的な方針変更として扱う。
- 外部から導入した公式skillへプロジェクト固有規則を書き込まず、憲法または各アプリの `AGENTS.md` に置く。

## 再利用性

- 憲法は複数のアプリやプロジェクトで再利用できる内容にする。
- 特定のサービス、製品、クラウド、framework、ライブラリ、アプリ名に依存する規則は原則として記載しない。
- 技術固有・アプリ固有の規則は、各プロジェクトの `AGENTS.md`、設計書、または設定ファイルに置く。
- 固有技術への言及が不可欠な場合は、汎用的な原則と分離し、その技術を利用する範囲だけに適用する。
